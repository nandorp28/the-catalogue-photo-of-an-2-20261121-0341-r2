A studio catalogue photo of an impossible gadget: a tin can of AQUA-NADA "DEHYDRATED WATER — JUST ADD WATER" (net wt 0 g), with exactly one accessory — a glass of water. Rendered in pure Python stdlib (bitmap font + hand-rolled PNG encoder), deterministic.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, ~16 KB). `python3 main.py --check` validates the render without writing.
